The danger in the Cyber world

Here's a short but detailed table explaining the risks bought by each attacks

Type of Attack Description
Malware Malicious software that damages, disrupts, or gains unauthorized access to a system, often hidden in downloads or email attachments. Example: a cracked software installer secretly stealing browser-stored passwords.
Phishing Fake emails or messages impersonating trusted companies to trick victims into revealing passwords or banking details. Example: a fraudulent Microsoft 365 login page used to steal employee credentials.
Ransomware Malware that encrypts a victim's files or locks their system, demanding payment for their release. Example: WannaCry encrypting files and demanding a Bitcoin ransom.
DDoS Attack Overwhelms a website or service with massive traffic from a network of infected devices (a botnet), making it unavailable to real users. Example: millions of requests flooding a server until it goes down.
SQL Injection Malicious SQL code inserted into poorly secured input fields to view, alter, or delete database data. Example: entering a crafted string to bypass a login form's authentication.
Zero-Day Attack Exploits a software vulnerability that developers don't yet know about, before any patch exists. Example: attackers exploiting an unpatched browser flaw ahead of an official fix.
Man-in-the-Middle (MITM) An attacker secretly intercepts communication between two parties, often on unsecured public Wi-Fi, to monitor or steal data. Example: credentials captured over public Wi-Fi through packet sniffing.
Password Attack Automated attempts to guess or crack a password using techniques like brute force or dictionary attacks. Example: repeatedly testing password combinations to gain unauthorized SSH access.
